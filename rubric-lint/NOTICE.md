# NOTICE

rubric-lint vendors or derives from the following MIT-licensed
sources. The license texts ship in `vendor/` alongside the material
they cover.

## Vendored verbatim

- **ryvn-dev/no-misread** (`vendor/nomisread.py`, `vendor/LICENSE-no-misread`)
  Fetched from `github.com/ryvn-dev/no-misread`, `lint/nomisread.py`,
  branch `main` (fetched 2026-11). Used for: the burstiness rhythm
  measurement (`rhythm()` - stdev_words AND band_share gate, plus the
  `FLAT_FOR_YOU` calibrated profile comparison this service feeds from
  `voice.json`), the sentence splitter (`sentences()`), the code/quote/
  URL exclusion semantics (`strip_code()` - reimplemented offset-
  preserving in `rubric_lint.mask_body()`), the narrative skeleton
  counters (`narrative()`, `count_drumbeats()`), and the compiled
  structural regexes reused as rules (`WORN_WORDS`, `CONTRAST_FRAME`,
  `THROAT_CLEARING`, `WRAP_UP`, `FALSE_EMPHASIS`, `FALSE_AGENCY`,
  `HEDGE_STACK`, `MIRROR_CONTRAST`, `TRICOLON`, `PASSIVE`,
  `TRANSITION_OPENER` via `narrative()`).

  `auxiliaryVerbs`, `abbreviations`.

## Own layer (no external source)

- **RU rules** in `rubric_lint.py` (`ru-stamp` marker regexes,
  `ru-nominalization` suffix density, `ru-long-sentence`,
  `ru-negation-reframe`, `ru-typography`): written for this service.
  Marker list is generic канцелярит/штампы plus tropes mined from
  `fixtures/humanizer/ai_flop/ru.txt` (per issue #80 - our own flop
  corpus, not a translated list). No ru-text/krrkt dictionaries were
  vendored; the score formula is a saturating hyperbola
  (100*rate/(rate+25)) in the same weighted-hits-per-words shape.

- **`voice.json`**: generated by `tools/learn_voice.py` from
  `fixtures/humanizer/clean_human/{en,ru}.txt` - per-language rhythm
  calibration for the burstiness `flat_for_you` comparison (vendored
  nomisread convention).

- **`python-build-standalone`** (`python/`, gitignored): Astral's
  prebuilt CPython used as the container interpreter (Apache-2.0 /
  PSF); materialized on the host by `fetch_python.sh`.
